## 4 · HOW TO OPERATE (the short version — the workflow files govern)

- **W2** produces a one-page decisions map (injustice units with quotable acts · concept-teaching schedule · heat map · plants/re-arms · budgets). Operator approves the map before W3 runs — structural notes are cheap here and expensive later.
- **W3** derives one brief per scene, mechanically, per the template's laws. It writes NO prose (only powerstart candidates + verbatim XFERs). Canon collisions surface as OPEN items with proposed -adapted fixes; the operator rules on them BEFORE any writer session.
- **W4** runs the session protocol: **one fresh, folderless writer conversation renders the whole promo, one scene at a time.** The writer's context = the preamble + `writer_constitution.md` pasted whole + the current brief; prior scenes accumulate in-session; NOTHING else ever enters it. **The clean room is absolute — a writer that can see pipeline files, prior versions, or this folder produces a voided artifact (this happened once; treat it as a hard law).** Each draft scene goes through the line editor (fixes + log) and the cold restatement reader before the operator sees it.
- **The operator gate between scenes:** his notes triage into three bins — REPEAT CLASS (an editor miss → strengthen that codex class), NEW CLASS (add ONE line to constitution or codex, with his pair as exemplar, naming what it merges into), PURE TASTE (apply to the scene, deposit his lines to the exemplar bank, add NO law). Operator-authored replacement lines are used VERBATIM. Log per scene: note count + repeat share — both should trend down; if repeats rise, tune the editor, don't add rules.

## 5 · HARD LAWS (violating any of these is how the last three pipelines died)

- **Mass budgets:** the constitution stays one page + voice model; codex classes merge on entry; briefs are seven blocks. Never add a rule without naming what it absorbs. Rule-count growth is this system's documented failure mode.
- **Agents never judge quality.** They enforce fixed rules (grep, codex classes, restatement). The taste-grader is demoted permanently (measured ρ≈0.09 against the operator's ear). Unclassed concerns are FLAGGED to the operator, never fixed by taste.
- **Control gate:** no new rule or agent behavior bites live work until it runs clean on both controls.
- **Canon:** XFERs word-for-word or not at all; adaptations only as logged -adapted rows; writers never mint a number; HARD BLOCKS absolute; hero-facts stated as truth in briefs.
- **No promo ships without the operator's independent read of the assembled whole.** A passed gate is a measurement, never a verdict.
- Follow the workflow files verbatim — never reconstruct a workflow from memory.
