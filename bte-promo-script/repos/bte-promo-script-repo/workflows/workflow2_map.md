## 1 · SKELETON INHERITANCE (flow is inherited, not invented)

A functional skeleton (pinned in W1, pasted, or named from the library) **owns the beat ORDER and each beat's structural FUNCTION; the Spine owns the CONTENT poured into each slot.** If one is in play, W2 never re-derives order — that freedom is exactly what invents setup-beat openings. Discipline: **1:1 by default** (no beats added, dropped, merged, or reordered silently; split/merge only with an explicit flag + operator sign-off) · **no invented connective beats** ("to set up the next one" IS the failure mode — the source's BECAUSE chain is already load-bearing; trust it) · **preserve FUNCTION, never surface** (transplant "accidental contact with the force that later inverts status," not the dragon) · **transplant-drift flag** when an inherited slot carries the source show's tonal DNA — re-tone the realization to the target register. An angle that fits no skeleton is flagged to the operator before mapping continues; free-derivation is a declared risk, never a default.

## 2 · PRE-CONSTRUCTION — THE SPINE (~400 words of decisions, each with a "from" tag tracing to Essence)

Load the Essence block (Three Pillars · Identity · Combat Behavior · Power Source · Voice Register · Setting Essence). Then derive:

- **Virtue** (one word, from Identity) · **Throughline** (one binary-testable sentence, from Identity — the internal per-beat test) · **Container** (from Setting Essence — the container matches the entry-point setting; catches setting drift before beats exist) · **Combat / Power** (from their Essence dimensions).
- **RELATABLE THRULINE** (from ONE pillar): the pillar translated into a universal human experience a cold listener recognizes in ten seconds — "everyone has had something they needed to keep hidden," "everyone has been underestimated." **Strip-the-proper-nouns test:** if what remains names a show mechanic, keep abstracting until what remains is human. This is the empathy nerve every injustice unit presses on — an injustice that's unfair in plot terms but doesn't touch the thruline builds story, not empathy.
- **WHY NOW** (one sentence): what makes this happen TODAY — a clock, a deadline, an event. Every scene feels it. No natural WHY NOW in the material = flag it; building without one produces episodic structure.
- **STAKES LADDER** (escalating in DOMAIN: social → physical → existential; same domain three times is volume, not escalation) · **INJUSTICE TYPE ROTATION** (social / material / relational / moral / existential — no two consecutive units share a type) · **INJUSTICE TRAJECTORY** (severity RISES across thirds — more taken, more undeserved, more irreversible; **the worst injustice lands in the final third, never the open** — a promo can pass density and rotation and still frontload its peak in scene one, then fade; this axis exists to catch exactly that).
- **PROMISE THREADING** (the 2–3 elements the audience installs for, mapped per third; a third with zero threading is advertising a different show) · **BOFU PINS** (the HARD BLOCKS list verbatim + the tonal one-liner *"this promo promises [X]; the show is [Y]"* — [X] operator-confirmed).

The Spine block prints at the top of every map delivery, "from" tags included.

## 3 · THE SCENE MAP (the v4 continuity layer — unchanged from v1)

Scenes in order; per scene: **POSITION** (cold open / mid / anchor / cliff) · **IN → OUT** (entry and exit state, one sentence each; **OUT(N) = IN(N+1), diffable — scenes are a chain, never islands**) · **TIME** (relative to the last scene; jumps declared and bridged by a voice or carried object) · **CARRY** (objects, wounds, debts, promises persisting across the seam — each touched in the next scene's opening) · **BECAUSE** (this scene happens BECAUSE of [named prior-scene event]; **every seam reads THEREFORE or BUT, never AND-THEN**) · **INJUSTICE UNITS** (ACT quotable · PUNISHER + citation · GAP one sentence) · **CONCEPT CAP** (3–4 ideas, cold opens lower) · **SEAM** (the voice that carries the listener out) · **BUDGET** (derived bottom-up — §7).
**Across the map:** each unit adds a dimension (peer → authority → structural → intimate) — never the same humiliation, **and never the same victory, re-staged**; **REVEALS ARE SPENT ONCE** (a small-stage demonstration that pre-spoils a big-stage payoff is a map defect); **the hero answers in every unit** — the ONE marked silence (if any) is a silence that IS an act, declared here.

## 4 · BEAT CONSTRUCTION LAW (how the units inside every scene get built — internal)

**THE LOOP — six questions on every beat:** (1) What happens? — one sentence: character, action, outcome. (2) **Who is driving it?** — a named character, never "the situation"; on injustice beats the antagonist, on positive beats the ally or protagonist. (3) **Why? — BECAUSE [previous beat].** If you can only write AND-THEN, the link is broken. (4) What is different now? — new fact, position, or constraint; nothing moved = dead weight. (5) **What choice is the protagonist making? — THE FURNITURE TEST: remove the protagonist; if the beat still happens, they're furniture. This is where a passive hero dies at the map, before any writer exists.** (6) What is the cost? — injustice beats: what's lost; positive beats: what new vulnerability opens; no cost = leaked pressure. Two consecutive beats failing the loop → stop building forward; the problem is the Spine.

**THE ANTI-SETUP GATE (every beat — hard flag):** every beat is a **witnessed event with a named driver acting on the protagonist in real time** — never a status, a mood, or world-texture. A "protagonist at zero" beat is dramatized as an injustice event with the virtue visible, never narrated as standing. No two consecutive setup beats anywhere; none in the opening run. A backstory-delivery scene with no witnessed event is a setup SCENE — the same failure at scene grain — and does not survive the gate.

**THE COLD OPEN (Beat 1 protocol):** anchor on one of three forms — a concrete failing attempt · a specific rupture landing on the POV · a contradiction the character is living inside. No narrator thesis, no environmental establishing. Identity + genre fuse within a sentence. Embed the structural lock (why the obvious solution doesn't work — a paradox, not just a problem). Verify agency (furniture test). **Strike test:** cover the first sentence; if the rest still works, cut it — repeat until sentence one is load-bearing.

**And while building:** the **Gap Test** (the previous beat's ending PUSHES into this one; inventing time/location/context between beats = a gap — distinct from BECAUSE, a beat can pass one and fail the other) · **virtue visible BEFORE the punishment lands** (the audience holds what the antagonist doesn't; the strongest injustice is inverse — technically right, structurally wrong) · **positive beats carry their cost in the same beat** and leave the audience MORE anxious, never less · **antagonist echoes planned** 2–3 beats past any antagonist exit · **the over-delivery check at the climax:** the currency stays *injustice-endured / knowledge*, never *power-displayed* — the secret threatens, it does not detonate.

## 4b · SET-PIECE REALIZATION (every committed move gets its most striking body — HERE, not downstream)

The map's events are not summaries — each committed move is realized as **the single most striking filmable event that enacts it**. "His name appears on the board" is underbuilt; "the board glitches, scrambles, and re-selects him at one hundred percent confidence" is the realized move — the system's insistence IS the institutional depth. **The two kinds of invention, kept apart: DEPTH is required** — inventing the *staging* of a move the structure already committed (the glitch, the frame-skip, the hairline floor-crack), every mechanic and quantity in it traceable to a world-doc line. **SCOPE is banned** — new agents, subplots, mechanics, lore claims, or quantities the structure never committed fire **CANON-FABRICATED**: re-ground, tag INVENTION for operator sign-off, or fall back to the committed move. Test per set-piece: does it enact a committed move with a bible-true body (keep), or introduce a move/rule/number the map never had (cut)?

**Engine requirements + distribution (from the taxonomy — checked at the gate):** the engine's required beats are present (Secret Identity → a near-exposure beat; Underdog Awakening → power-activation delayed past ~40%; Self-Sacrifice → a bond demonstrated in the first 30% + an internal refusal) · no 30%-of-runtime window without a TURN (a stretch where the audience's model never shifts is a flat stretch) · setup-tagged material stays under a quarter of the map · the first beat of every scene is charged, never state-setting.

## 5 · THE TEACHING SCHEDULE

Every world concept → the ONE scene that teaches it, through action or a staked mouth, before first use — never a lecture or roll call. A concept no scene can afford under its cap forces a cut or restructure HERE. A canon XFER requiring an untaught system is scheduled where the system is taught, or moved.

## 6 · HEAT + DENSITY ARCHITECTURE

Beats tagged **PHYSICAL/INTIMATE** or **PROCEDURAL**: no conversation-sized span all-procedural; the genre engine fires physically in every third. **Injustice density: no third below 50% injustice; never three consecutive beats without injustice or a world-expanding moment.** Tonal variety: at least two registers — not all dread. The world should read with EXCITEMENT, not respect.

## 7 · PLANTS, CLIFF, LENGTH

- **Plants — run BOTH directions:** forward (each early scene names what it can plant) and **backward from the cliff** — list what the climax and cliff pay off, then verify every payoff has a seed planted earlier; a payoff with no plant gets one planted (the arena floor shatters → a hairline crack at the humiliation peak). Plants sit near their payoffs; every withheld truth carries a **re-arm schedule** (≥2 touches where the world gets the hero wrong).
- **THE CLIFF — built in three passes:** (1) draft the natural endpoint; (2) **the MAXIMUM WITHHOLDING REWRITE** — the version that withholds most, opens the most questions, and puts the protagonist AT the threshold, hand on the door, present progressive, with something arriving — subject to the one-way ratchet (the threshold only ever moves toward MORE withholding); **one singular DATED must-resolve loop foregrounded** (a clock with a number), closing on forward questions asked as questions, then the CTA (required); (3) **the fidelity pass** — maximum withholding *pushes toward* detonating the secret into a visible win; check the rewrite against the pinned HARD BLOCKS and the tonal one-liner. Exhale test · expansion test · threshold test · verb-tense test all pass or the map doesn't lock.
- **LENGTH — WORDS FOLLOW EVENTS, NEVER THE REVERSE:** the floor (3,500 hard, ~4,500 target) is satisfied by **counting staged events** at natural density (a turn ≈ 15–25 spoken words; a narration beat ≈ 1–2 sentences). Short of the floor = add distinct material, shrink the promo, or route to W1 — never close the gap with budget; a top-down word target over thin events produces narration fill and repeated beats (the documented death of the first v4 run; house precedent: the tight Midnight shipped over the padded one). A word count is an output of the event list, never an instruction to a writer.

## EXIT GATE (once, full map — verify by quoting; a check you can't quote hasn't passed)

1. **Chains:** the IN→OUT chain diffs clean (OUT(N)=IN(N+1), every seam) · **the BECAUSE chain read cold, end to end — each link connects to the PRIMARY action of the previous beat; THEREFORE/BUT at every seam, never AND-THEN** · TIME jumps declared and bridged · every CARRY item lands.
2. **Anti-setup (hard flag — blocks lock):** every beat a witnessed event with a named driver; no consecutive setup beats; no setup scenes; "at zero" dramatized, never narrated.
3. **Thruline:** stated as a universal experience (strip-the-nouns test passes), anchored to a pillar; the opening lands on the nerve in the first ten seconds; the injustice units press on it, not just on plot.
4. **Agency:** every beat passes the furniture test; the hero answers in every unit (or the one declared act-silence).
5. **Injustice architecture:** density floors met (§6) · no two adjacent units share a type · **trajectory rises — the worst injustice sits in the final third; if the open tops everything after it, flag with options to raise the back half** (soft flag).
6. **Structure:** every PUNISHER's citable ACT quoted · every concept has one teaching home before first use · reveals spent once · no repeated victory mechanic · inheritance checks (order/count/function preserved; splits logged) if in inheritance mode.
7. **Withholding:** exhale · expansion · threshold · verb-tense — all four (hard).
8. **Length:** event count carries the floor at natural density; budgets are outputs.
9. **WRONG-SHOW CONTRACT (hard flag — blocks lock):** final third, cliff, and premise frame against the pinned HARD BLOCKS and the operator-confirmed tonal one-liner; **currency at the cut is injustice/knowledge, never power-displayed.** A failure fires the **BOFU HARD STOP**: surfaced loudly, never buried; cleared only by the **contested override** — the operator must contest the block's *applicability* in writing ("the world file is stale, canon allows this" with a pointer, or a logged CPI experiment); "it's cooler" does not hold; a NO-GO can stand; accepted overrides are logged.
