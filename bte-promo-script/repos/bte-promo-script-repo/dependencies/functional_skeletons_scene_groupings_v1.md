# FUNCTIONAL SKELETONS — SCENE GROUPING BLOCKS v1

**Companion to the functional skeleton library (`Functional Skeletons · Three Pillars`).** W2 v2's Scene Assembly stage reads these in inheritance mode: the grouping is inherited, not invented. Each block was derived once — from the source cracked script where full text or beat maps exist (Weapons, IMF5, Dragon Battle, Live Action 2.0 verified against `Cracked_Scripts_SceneBreakdown_v1.md`), from the skeleton's own beat logic otherwise (marked *derived — verify on first use*). Beat numbers reference the library's beat definitions.

**Norms (from the six cracked scripts):** 5–7 scenes standard; long-form skeletons (FITP, Phoenix/Love Bite, Pawn Shop) run 8–9. One ANCHOR scene at 25–35% of script length. Connective scenes legal but ≤~250 words and must still turn a state. Every scene break carries a NAMED-NEXT on-page.
